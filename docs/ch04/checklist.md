# MewCode 第四章验收清单：Agent Loop

## Agent Loop 验收
- [ ] 同一用户请求内，模型可以连续触发至少两个工具步骤后再给出最终回答。
- [ ] 当模型不再请求工具时，本轮结束并保存最终 assistant 文本。
- [ ] 默认最多执行 24 个工具步骤。
- [ ] 达到配置的最大工具步骤数后，不会执行下一步工具调用。
- [ ] 工具失败会作为结构化工具结果回灌给模型，而不是让程序崩溃。

## 多工具调用验收
- [ ] OpenAI Provider 可以从同一次流式响应中解析多个 `tool_calls`。
- [ ] Anthropic Provider 可以从同一次流式响应中解析多个 `tool_use` block。
- [ ] `ChatResponse` 和 `StreamChunk` 可以承载多个工具调用。
- [ ] 没有工具调用时，Provider 仍能返回纯文本响应。
- [ ] 工具调用包含稳定 id，工具结果可以按 id 回填。

## 会话回填验收
- [ ] 一次 assistant 工具响应可以在会话历史中记录多个工具调用。
- [ ] 多个工具结果会按模型原始工具调用顺序写入会话。
- [ ] 并发读工具完成顺序不同，不会改变写入会话的结果顺序。
- [ ] OpenAI 消息 payload 中 tool result 能对应原始 tool call id。
- [ ] Anthropic 消息 payload 中 tool result 能对应原始 tool use id。

## 工具分批执行验收
- [ ] `ReadFile`、`Glob`、`Grep` 被视为安全读工具。
- [ ] `WriteFile`、`EditFile`、`Bash` 被视为不安全工具。
- [ ] 同一轮响应中多个安全读工具可以批量执行。
- [ ] 同一轮响应中多个不安全工具按模型顺序串行执行。
- [ ] normal mode 下 `WriteFile`、`EditFile`、`Bash` 不再触发用户确认。

## Plan Mode 验收
- [ ] 输入 `/plan` 后，REPL 进入 Plan Mode。
- [ ] 输入 `/do` 后，REPL 回到正常执行模式。
- [ ] 输入 `/plan 修改某文件` 会切到 Plan Mode 并立即执行剩余请求。
- [ ] 输入 `/do 创建文件` 会切回正常模式并立即执行剩余请求。
- [ ] Plan Mode 下 `ReadFile`、`Glob`、`Grep` 可以执行。
- [ ] Plan Mode 下 `WriteFile`、`EditFile`、`Bash` 不会实际执行。
- [ ] Plan Mode 下不安全工具被拦截后，模型能收到结构化结果并输出计划。

## Textual 界面验收
- [ ] 多步工具调用过程中，每个工具调用都有可见状态行。
- [ ] 工具执行中显示动态 spinner。
- [ ] 工具完成后状态行变成对勾或失败标识。
- [ ] 多次工具调用结束后，最终状态显示 Done。
- [ ] `/plan` 和 `/do` 会在界面中给出模式切换反馈。
- [ ] Esc 取消后，当前状态显示 interrupted，输入框恢复可用。

## 行模式验收
- [ ] 强制行模式下，普通请求也走 Agent Loop。
- [ ] 行模式中可以看到工具开始和工具完成输出。
- [ ] 行模式支持 `/plan` 和 `/do`。
- [ ] 行模式下 `/quit` 或 `/exit` 正常退出。

## 取消与错误验收
- [ ] 模型流式输出期间按 Esc，Agent 在安全检查点停止。
- [ ] 工具执行前检测到取消时，不再启动新工具。
- [ ] 不可恢复 Provider 错误会产生错误事件，界面不打印 Python traceback。
- [ ] 工具异常会被转换为结构化工具结果。

## 范围边界验收
- [ ] 本章没有实现长期权限系统。
- [ ] 本章没有实现上下文压缩。
- [ ] 本章没有实现用户确认机制。
- [ ] 本章没有实现子 Agent 委派。
- [ ] 本章没有实现复杂系统提示词组装。

## 端到端验收
- [ ] 在示例项目中输入“帮我找项目入口并说明原因”，观察到 Agent 搜索文件、读取候选文件并最终回答。
- [ ] 在 normal mode 输入“创建 demo 文件，写入内容，再读取确认”，观察到文件被创建、读回结果并最终回答。
- [ ] 输入 `/plan 修改某文件`，观察到 Agent 只读取上下文并输出计划，不修改文件。
- [ ] 输入 `/do` 后再次请求创建文件，观察到文件可以被实际写入。
- [ ] 构造模型持续请求工具的场景，观察到达到配置的最大工具步骤数后停止继续执行。

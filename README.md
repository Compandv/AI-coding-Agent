# MewCode

MewCode is a Python terminal AI coding assistant. The first stage implements a pure streaming chat REPL with configurable Anthropic Claude and OpenAI providers.

See [docs/ch02/spec.md](docs/ch02/spec.md), [docs/ch02/tasks.md](docs/ch02/tasks.md), and [docs/ch02/checklist.md](docs/ch02/checklist.md) for the first-stage blueprint.
